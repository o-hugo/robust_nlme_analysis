# robust_nlme_analysis
 Implementação do método aproximado para inferência em modelos não-lineares de efeitos mistos com distribuições robustas (Student-t, slash e normal contaminada), baseado no artigo "Fast inference for robust nonlinear mixed-effects models" (Gomes et al., 2022). Este repositório fornece scripts e notebooks para aplicar estas técnicas em dados de curva de crescimento e farmacocinética, permitindo estimativas eficientes mesmo na presença de outliers ou dados com caudas pesadas. Inclui ferramentas para visualização, diagnóstico e comparação de modelos com diferentes distribuições.
